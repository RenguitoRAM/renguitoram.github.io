# Подключение формы: Telegram + почта

Сайт на GitHub Pages статический: у него нет своего сервера. Заявки принимает бесплатный скрипт Google Apps Script (`Code.gs`). Он пересылает сообщение вам в Telegram и на studio@kocuba-aa.ru, а сайт показывает «Вы сделали первый шаг» только после того, как скрипт подтвердил доставку.

Нужен Google-аккаунт. Займёт около 15 минут.

## 1. Бот в Telegram

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Имя бота: например, `AI OASIS заявки`. Username: например, `aioasis_leads_bot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA...`. Никому его не показывайте и не вставляйте в чат с Claude.
4. Откройте своего нового бота и нажмите **Start** (или отправьте `/start`). Без этого бот не сможет вам писать.

## 2. Скрипт Google

1. Откройте https://script.google.com и нажмите **Новый проект**. Назовите его `AI OASIS форма`.
2. Удалите всё в файле `Код.gs` и вставьте содержимое файла `Code.gs` целиком. Нажмите значок дискеты (Сохранить).
3. Слева шестерёнка **Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство**:
   - `TG_TOKEN` = токен от BotFather
   - `EMAIL` = `studio@kocuba-aa.ru`
   - Нажмите **Сохранить свойства**.
4. Вернитесь в редактор (значок `<>`). В списке функций сверху выберите `findChatId` и нажмите **Выполнить**. Google попросит разрешения: **Проверить разрешения** → выберите аккаунт → **Дополнительно** → **Перейти к проекту** → **Разрешить**.
5. Внизу в журнале появится строка `chat id: 123456789`. Добавьте свойство `TG_CHAT_ID` с этим числом.
6. Выберите функцию `testSend` и нажмите **Выполнить**. Должны прийти тестовое сообщение в Telegram и письмо на почту. Если письмо пришло в «Спам», отметьте его как «Не спам».

## 3. Публикация скрипта

1. Справа вверху **Начать развёртывание** → **Новое развёртывание**.
2. Шестерёнка рядом с «Выберите тип» → **Веб-приложение**.
3. Описание: `форма сайта`. **Запуск от имени**: «Я». **У кого есть доступ**: «Все».
4. **Начать развёртывание**. Скопируйте **URL веб-приложения**: он начинается с `https://script.google.com/macros/s/` и заканчивается на `/exec`.
5. Пришлите этот URL Claude (это не секрет: по нему можно только отправить заявку). Его нужно вписать в сайт в строку `var FORM_ENDPOINT = '';`.

Если потом поменяете `Code.gs`, сделайте **Управление развёртываниями** → карандаш → Версия: **Новая версия** → **Развернуть**. URL останется прежним.

## Защита и ограничения

- Токен бота хранится только в свойствах скрипта, на сайте его нет.
- Есть скрытое поле-ловушка от спам-ботов и ограничение 40 заявок в час.
- Google позволяет бесплатно отправлять около 100 писем в день.

## Важно про персональные данные

Заявки проходят через серверы Google и Telegram, они находятся за рубежом. По 152-ФЗ первичный сбор персональных данных граждан РФ должен вестись в базе на территории РФ, и для оператора действует обязанность уведомить Роскомнадзор. Эту схему стоит показать юристу. Возможный вариант на будущее: сохранять заявку сначала на российском сервере (например, Yandex Cloud Functions) и уже оттуда пересылать.
